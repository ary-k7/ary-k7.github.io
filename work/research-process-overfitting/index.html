Research process: searching thousands of variants without fooling myself

An AI-agent search loop for strategy research, run under rules I set in advance. Every trial is logged, parameters must sit on a plateau, holdout looks are rationed, and most candidates fail.

The question

If a machine can try thousands of strategy variants overnight, the best one will look good by chance. The question is how to search that widely and still tell an edge from luck.

My answer is to fix the judge before the search starts, count every trial, and accept that most candidates fail.

What I did

  • Adapted the “autoresearch” pattern (an agent edits one strategy file, a fixed backtest scores it, the change is kept or reverted) to trading. AI agents run the search loop and write most of the code. I set the goals, the data splits, the rules and the verdict criteria in advance, in a fixed harness the loop does not edit.
  • Kept a cross-run ledger of every run, agent trial, grid evaluation, holdout look and forward test, so each result is judged against how much was tried in its family.
  • Applied the same checks to every candidate:
    • Plateau rule. A parameter’s one-step neighbours must perform almost as well as it does; an isolated peak is rejected.
    • Delay test. Entries and exits are delayed to check that the result does not depend on a lucky minute.
    • Block bootstrap for the drawdown distribution.
    • Family Deflated Sharpe, using the effective number of trials.
    • Holdout rationing. A small, fixed number of looks per holdout.

Three examples of the process saying no:

  • Natural-gas expiry book: rejected. It met target on training and validation data (Sharpe 2.55 and 2.50), then failed the holdout (Sharpe −0.07). One holdout day, a January price spike, lost about four times the worst training drawdown. Dropping that day after seeing it would have been exactly the fitting the holdout exists to catch. Family Deflated Sharpe was 0.02, and the loop was stopped.
  • Crude breakout buyer: dropped. None of 288 buyer setups passed the plateau rule; the chosen setting’s neighbours had a median Sharpe of 0.72.
  • Equity momentum timing luck. On the loop’s target score, where 1.0 meets the goal, a month-end rebalance scored 0.80 on development data but 0.34–0.57 when shifted to other days, and 0.52 on the holdout. Staggered tranches replaced it.

My first project, in Jun 2026, brute-forced 4,536 rule combinations on 5-minute stock data. These rules exist to guard against exactly that kind of search.

What would break this

  • Backfilled verdicts. Some pass and fail verdicts were recorded after the fact, not at the time.
  • Stale holdouts. Many holdouts had already been opened by earlier runs, so they no longer test anything cleanly.
  • The trial count drives the verdict. The crude book’s Deflated Sharpe is 0.37 on the effective-trial estimate and 0.02 on the raw count. The answer depends on an estimate.
  • The agent is not neutral. It proposes the changes, and the rules only limit what it can keep. I judge the verdicts, and an interviewer is right to ask where my judgement starts.

What I would do next

Treat the 18 locked forward tests as the only clean evidence, and register every verdict before the result is seen.
